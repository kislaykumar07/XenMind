# XenMind Frontend

Lovable-built frontend (TanStack Start v1, React 19, Vite 7, Tailwind v4).
On 2026-10-24 the source was extracted from the single-file dump
(`xenmind_frontend_code.md`, kept for reference) into the real file tree here.

## Backend contract — FIXED

`src/lib/api.ts` is the single adapter between this app and the FastAPI backend:

- `VITE_API_BASE_URL` = backend **origin only** (e.g. `http://127.0.0.1:8000`).
  A trailing `/api` in the value is stripped automatically.
- All backend routes are under `/api` and use snake_case JSON. The adapter
  converts to the app's camelCase types (`title → name`, `passed_count →
  assertionsPassed`, scenario/agent names resolved for display, etc.).
- No other file should call the backend directly.

Previously this layer called `POST /runs` with `{ scenarioId }` and expected
camelCase responses — that would have 404'd / rendered blank against the real
backend. The fixed adapter was typechecked and run end-to-end against the
live backend (scenarios, runs, events, replay, versions, compare) on 2026-10-24.

Without `VITE_API_BASE_URL`, run lists fall back to clearly-labelled demo data
and run requests refuse instead of faking a test — that behaviour is unchanged.
